# Задача Речной бой
Ограничение по времени: 1 секунда
___
Поле в игре «Речной бой» представляет собой полоску длины n клеток и шириной в одну клетку. Где-то на поле расположен корабль из k клеток (k 6 n). Какое наименьшее число выстрелов необходимо, чтобы гарантированно потопить корабль? После каждого выстрела сообщается его результат: «мимо», «ранен» или «убит».
### Формат входных данных
Первая строка входных данных содержит целое число n (1 <= n <= 10^9).
Вторая строка входных данных содержит целое число k (1 <= k <= n).
### Формат выходных данных
Выведите одно целое число — количество выстрелов.
## Инстркуция по запуску
### C
```
cd ./c_code
gcc main.c -o output
./output
```
### C++
```
cd ./cpp_code
g++ main.cpp -o output
./output
```
